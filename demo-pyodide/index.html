RevealPyodide plugin demo

In-browser Python execution — live editable code blocks on the slides.

Powered by Pyodide running in a Web Worker, with editing provided by Ace through the highlight-ace plugin.

1. Editable code block

Click the code below to enter edit mode. Press Esc to exit without saving, or Ctrl+Enter to commit your edits.

2. Auto-run on deck load

data-run-with-deck runs the block once when the slideshow finishes initializing. data-output-as-fragment reveals the output on the next click. data-run-on-edit re-runs on every edit.

3. Send stdout to a target on another slide

data-stdout="#someId" writes stdout into a specific element — here a <code> on the next slide. Useful for "show the error" / "show the result" layouts. 


# We have an error here:
for i in range(5, -1, -1):
    print(1.0 / i)

The output / traceback appears on the next slide.

4. A small playground

Edit the snippet, press Ctrl+Enter — the result re-renders inline. 


import math
print(", ".join(f"{n}! = {math.factorial(n)}" for n in range(1, 8)))

Cheatsheet

Plugin scripts:

  • highlight-ace.js — highlighting + editor
  • pyodide.js — Python execution

Per-block attributes (on <code>):

  • data-language="python" — required for the worker to pick it up
  • data-run-with-deck — run once on deck-ready
  • data-run-with-slide — run on every entry to the slide
  • data-run-on-edit — re-run on each edit commit
  • data-output-as-fragment — output appears as a reveal fragment
  • data-stdout="#sel" — route output into a specific element
  • contenteditable="true" — let the user edit
  • data-editor-in-place — overlay the editor instead of full-screen

Reveal.initialize({
