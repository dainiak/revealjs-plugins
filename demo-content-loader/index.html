7. PDF embedding — single page

data-pages="1,3;5-7" selects pages by number and range. Stacked vertically inside a scrollable container.

9. PDF embedding — pages as reveal fragments

Same selection but the pages animate one-by-one as fragments. r-stack stacks them in the same place; auto-fragmentize tags every page as a fragment.

Cheatsheet — one attribute at a time

External-content attributes (use exactly one per element):

  • data-inner-text="path" — replace inner content with text
  • data-outer-text="path" — replace element with a text node
  • data-inner-html="path" — replace inner content with parsed HTML
  • data-outer-html="path" — replace element with parsed HTML
  • data-pdf="file.pdf" data-pages="1,3;5-7" — embed PDF pages

Path with selector: file.html#cssSelector — only the matched fragment is loaded.

Inline JS generator: wrap a function expression in an HTML comment inside a data-inner-html / data-outer-html element with no path attribute value.

Custom actions: register {selector, init} objects under contentLoader.actions in Reveal.initialize(); init runs on every matching element after content is in place.
