RevealMath plugin demo

Math typesetting in reveal.js — MathJax-powered, with native fragment support.

Two interchangeable plugins ship in this repo: math.js (MathJax, supports SVG math too) and math-katex.js (KaTeX, faster). This deck uses math.js.

1. Inline math + definition box

\(...\) for inline math, \[...\] for display math. The .definition/.theorem/.proposition/.proof styles are provided by reveal-custom/css/extras.css.

Definition (compact set)
A subset of \(\bbR^n\) is called compact if it is closed and bounded.

2. Fragments inside a multiline formula

\step / \next / \vstep macros from extras.css wrap subexpressions in fragment classes — reveal.js animates parts of a formula on each click.

Binomial expansion
For \(a,b\in\bbR\) and \(n\in\bbN\):

\[\begin{array}{rl} (a+b)^n &\step{= \underbrace{(a+b)\cdot\dots\cdot(a+b)}_{n\text{ times}}} \\ &\next{= \sum\limits_{\next{k=0}}^\next{n}\next{\binom{n}{k}\, a^k b^{n-k}.}} \end{array}\]

3. Custom macros — preamble + Reveal config

The preamble option points at a <script type="text/latex"> tag whose body is fed to MathJax once at startup. The macros option provides additional per-deck shortcuts.

  • \(\bbR\), \(\bbZ\), \(\bbN\), \(\bbF\) — from preamble
  • \(\GCD(a,b)\) — \DeclareMathOperator
  • \(\card{X}\) — one-arg macro
  • \(\le, \ge\) — aliased to slanted versions via macros

4. Discrete logarithm

Fix a primitive root \(\alpha\in\Fstar\). For every \(x\in \bbF\setminus\{0\}\) the discrete logarithm \(\log_\alpha x\) has properties similar to the ordinary logarithm:

  • \(\log_\alpha (xy)=(\log_\alpha x + \log_\alpha y) \vstep{?}\next{\bmod \card\Fstar,}\)
  • \(x^{\log_\alpha y}=y^{\log_\alpha x},\)
  • \(\log_\alpha x = (\log_\beta x \cdot \log_\alpha \beta) \bmod\card\Fstar.\)

5. Math typeset inside SVG (MathJax only)

With math.js + options.svg.enabled = true, formulas inside SVG files are typeset on-the-fly when the SVG is loaded by the content-loader plugin.

6. SVG with reveal.js fragments

Native fragments work independently of the math typesetting — they live as .fragment classes in the SVG source.

7. fragidx-N shorthand

The math plugin contributes a CSS shortcut: class="fragidx-N" is equivalent to class="fragment" data-fragment-index="N". Useful when ordering fragments out of DOM order.
