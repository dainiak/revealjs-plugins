12. Build from JSON (pandas split orientation)

Drop a <script type="application/json"> inside the table. The plugin builds <thead> / <tbody> on the fly.

Click 1: sort by population. Click 2: sort by GDP. data-sort, data-highlight, click-to-sort all still work on top of the generated DOM.

13. Build from JSON (pandas records orientation)

Array of objects — what df.to_json(orient="records") produces. Column order is taken from the first object's keys.

14. Build from CSV

<script type="text/csv">. First row is the header. Quoted fields and escaped quotes ("") are supported.

Indentation is auto-stripped — you can keep the CSV pretty-printed in your HTML source.

15. Build from TSV with combined timelines

type="text/tsv" for tab-separated. Sort + highlight orchestration works exactly as with hand-authored HTML.

Step 1: sort by latency, highlight the two fastest. Step 2: sort by quality, highlight the strongest.

Cheatsheet 1: orchestration syntax

Sort: data-sort="<col>[ asc|desc][, ...] @<idx> | ..."

  • 2 desc @1 — sort col 2 descending at fragment 1
  • 2, 3 desc @1 — multi-key: col 2 asc, col 3 desc
  • @3 — empty step: revert to authored order

Highlight: data-highlight="<target>[, ...] @<idx> | ..."

  • 1 row, 1-3 rows 1–3
  • 2:4 cell at row 2 col 4
  • :2 entire column 2; 1-3:2-4 rectangle
  • @3 — empty step: clear all highlights

Cheatsheet 2: data sources, attributes & theming

Embedded data sources (alternative to authored <thead>/<tbody>):

  • <script type="application/json"> — pandas split, records, columns, index, or values matrix
  • <script type="text/csv"> / <script type="text/tsv"> — first row is header, RFC-4180 quoting

Other table attributes:

  • data-sortable-headers="false" disables click-to-sort
  • class="fragidx-N" on a cell promotes it to a reveal fragment

Theming (CSS variables):

  • --it-row-lit-bg, --it-cell-lit-bg, --it-cell-lit-border, --it-cell-lit-border-width
  • --it-dim-opacity, --it-anim-ms, --it-anim-ease, --it-fade-ms
