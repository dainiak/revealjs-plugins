reveal.js plugin showcase

A collection of plugins for richer reveal.js presentations.

By Alex Dainiak. One slide per plugin — click the link in the footer to dive into a full demo deck for each one.

Press Space / → to step through. Esc for slide overview.

What's in the bundle

  • mermaid.js — Mermaid diagrams with rich fragment-driven animation (declarative DSL: %%! show / highlight / dim / accent / spotlight)
  • highlight-ace.js — syntax highlighting + live editor (Ace), with stable-anchor line highlighting (data-line-anchors)
  • interactive-charts.js — Vega-Lite, Plotly, Bokeh charts driven by reveal fragments (data-vega, data-plotly, data-bokeh)
  • interactive-table.js — tables with scripted sort + cell/row/column highlighting tied to fragments
  • math.js / math-katex.js — MathJax / KaTeX math, with built-in \step/\next/\vstep fragment macros
  • inking.js — interactive whiteboard layered over slides (free drawing, math insertion, spotlight, SVG preload, JSON replay)
  • pyodide.js — in-browser Python execution with a live editor
  • content-loader.js — load external HTML/text/SVG/PDF into slide containers; register custom DOM actions

interactive-charts.js — click-driven chart narration

Vega-Lite parameters change on each fragment. Same engine handles Plotly and Bokeh too — one spec, one fragment list, one declarative file.

  • Reason — pure LLM call, fast.
  • Tool — HTTP, dominates the budget.
  • Observe — cheap parsing.
  • Answer — second LLM round-trip.
  • All four together — the full picture.

math.js — LaTeX with reveal fragments

MathJax-powered (also math-katex.js for KaTeX). Built-in \step / \next macros wrap subexpressions in reveal fragments — clicks animate parts of a formula.

Binomial expansion
For \(a,b\in\bbR\) and \(n\in\bbN\):

\[\begin{array}{rl} (a+b)^n &\step{= \underbrace{(a+b)\cdot\dots\cdot(a+b)}_{n\text{ times}}} \\ &\next{= \sum\limits_{\next{k=0}}^\next{n}\next{\binom{n}{k}\, a^k b^{n-k}.}} \end{array}\]

content-loader.js — load external content into slides

data-inner-html / data-outer-html / data-inner-text / data-outer-text for files; data-pdf for PDF pages; custom DOM actions for selector-based init logic.

  • The auto-fragmentize action below makes every child a reveal fragment.
  • It's just a custom action registered in Reveal.initialize().
  • You can register any matcher + DOM-init pair you need.
  • PDFs render via PDF.js.

cssanimation.js — declarative CSS animation

A small DSL inside a <script type="text/animation"> tag. Each next consumes one fragment beat — apply, show, hide, execute, reset, with during / delay for timing. 


initially
    apply color='red' to li[0,1]
    apply color='teal' to li.special
next
    hide li[2] during 500ms
    then
    show li[2] during 500ms delay 1000ms
    then
    apply 'font-size'='16pt' to li[2] during 1000ms
next
    apply 'font-size'='16pt' to li[0]
next
    reset

webcam.js — picture-in-picture for live talks

Two keys. The browser's getUserMedia stream stays local — no streaming elsewhere.

  • C — toggle the webcam on / off (small, in the corner).
  • Shift+C — toggle full-size, filling the slide area.

Useful when recording talks (persistent corner-cam) or for "open with a hello, then back to the deck" beats. Pairs nicely with inking.js — the whiteboard draws over the video too.
