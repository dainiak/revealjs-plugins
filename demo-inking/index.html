RevealInking plugin demo

An interactive whiteboard layered on top of any reveal.js slide.

Powered by Fabric.js + MathJax. Every shortcut below works on every slide of this deck.

1. Free-hand drawing

  • Ctrl+LeftClick+drag — draw freely
  • While drawing, the bottom toolbar lets you choose pen color and width
  • Shift+LeftClick+drag — erase strokes
  • Click+drag a stroke — select / move it
  • Del — remove selected elements

2. Math, spotlight, save

  • = — insert a LaTeX formula at the mouse, or edit the selected one
  • Alt+LeftClick or x — hold for a spotlight
  • q — show / hide the canvas
  • - — clear the canvas on the current slide
  • z — export current slide as SVG, or all slides as JSON for replay later

3. Preloaded SVG content

data-inking-canvas-src="a.svg::b.svg" — load multiple SVGs into the canvas. Each becomes a movable, resizable group.

4. SVG split into individual shapes

Append :split to a .svg path — every path inside the SVG becomes a draggable, recolorable element. Try moving the rings of the Venn diagram.

5. Preloaded canvas state — replay last lecture

JSON exported with z from another deck can be re-loaded here. Math nodes remain editable — click \(e=mc^2\) and press =, or just double-click it.

6. Annotate live

Use this slide as a chalkboard. Press = and type, e.g.

\sum_{k=1}^n k = \frac{n(n+1)}{2}

then drag the rendered formula anywhere on the slide.

Configuration cheatsheet

Per-slide: data-show-inking-canvas opens canvas on enter, data-hide-inking-canvas closes it. Preload via data-inking-canvas-src="path[:split][::path2]...".
